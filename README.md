# FreshHarvest

React storefront interface with products, product descriptions, account screens and informational pages.

## Project structure

- `src/pages/`
- `src/components/`
- `src/App.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/FreshHarvest.git
cd FreshHarvest
```



Install Node.js and npm, then run `npm install` and `npm run dev` in the application directory. Open the terminal URL.
